This repository contains the code and resources for the bachelor thesis "Volumetric Data Structures for Ray
Marching Clouds on the GPU: Implementation and Comparative Analysis of a Dense Grid, a Two-Level Sparse Grid, and NanoVDB"

The code can be found within 'rdv/src/grid_sandbox'. In there a 'shaders' folder contains all the GLSL computer shaders.
In the folder 'scripts' you can find the python scripts for measurements and RDV Map Classes.

Important: The data folder is missing from this repository due to its size. Please contact me for the original .pt and .nvdb files.
